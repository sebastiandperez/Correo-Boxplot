# Correo Boxplot

Cliente de correo desktop local-first. El MVP actual usa Vue 3 + Pinia + TypeScript dentro de Tauri v2, con un motor local Rust sobre SQLite + SQLCipher y sincronización JMAP en un Worker TypeScript.
